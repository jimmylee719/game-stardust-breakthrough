# 星塵突圍 Stardust Breakout

2D 合作生存射擊遊戲。純 HTML5 Canvas + Web Audio，無任何前端依賴。

**線上版：https://game-stardust-breakthrough-production.up.railway.app**（Railway，新加坡節點，最多 4 人一房）

## 執行

需要 Node.js 18 以上。

```bash
npm start
```

開啟 http://localhost:8765 。網址後加 `?boss` 可直接從 Boss 波開始（測試用）。

## 玩法重點

- **難度曲線**：敵人血量每波 +16%、速度 +3.5%、體型 +2.5%（上限 +60%），第 4 波起出現金色光環的精英（1.5 倍體型、3 倍血量、必掉道具）。玩家基礎火力下修（傷害 8、射速 0.16 秒），升級幅度也縮小（傷害 +20%、射速 +10%）。
- **敵人 AI**（`shared/constants.js` 的 `AI`）：追擊者遠距離時會從側面包抄成包圍網；飛鏢繞飛後直線突進；射手保持距離帶風箏、第 5 波起預判玩家移動射擊（橘色子彈）、第 6 波起側移閃避來襲子彈、第 8 波起佈感應地雷（靠近或逾時炸成 8 枚碎片）；第 6 波起有 50% 機率改成兩側夾擊隊形。
- **雷射兵**（紫色，第 5 波起）：遠距鎖定，虛線預警 1.1 秒（前 70% 會追蹤你），鎖死後發射 0.35 秒貫穿雷射（22 傷害）。看到虛線就離開那條線。
- **Boss 雷射掃射**：三個階段都可能出現；充能 1 秒後從你的一側掃到另一側，狂暴階段更長。
- **雷射道具**（淡藍）：5 秒內按住射擊改射貫穿光束，每秒傷害為子彈傷害 × 7，適合清 Boss 與整列敵人。
- **升級節奏**：每 2 波三選一強化一次，Boss 擊破後必給。
- **組合技**：兩個特定升級各至少 1 級就啟動，升級卡上會用橘字提示「選這張會啟動哪個組合技」，啟動時大字宣告並顯示在 HUD。7 組：彈幕牆（穿甲 + 反彈：反彈時分裂成兩發）、吸血爆裂（汲血 + 連鎖爆裂：爆裂每波及一敵回 2 HP）、導引蜂群（追蹤 + 僚機：僚機射速加倍、子彈強力追蹤）、震撼彈（強化彈頭 + 巨型彈體：命中僵直 0.3 秒並擊退）、餘燼（高速裝填 + 連鎖爆裂：15% 子彈點燃 3 秒）、幽靈衝刺（衝刺冷卻 + 推進器：衝刺穿過造成 40 傷害）、護盾回充（裝甲 + 汲血：每 20 擊殺得一層護盾）。定義在 `shared/constants.js` 的 `SYNERGIES`。
- **20 波通關**：擊破第 20 波的「殲滅者 Ω」即突圍成功，+5000 分進入勝利畫面；按 Enter 繼續無盡模式（敵人持續變強、HUD 標示「無盡」），Esc 結束並結算。多人由房主決定；每日挑戰通關直接結算。
- **Boss**：體型約原本 2 倍，攻擊模式有環狀彈幕、扇形連射、旋轉螺旋、橫向彈牆（留缺口）、紫色追蹤能量球、衝撞、召喚。每 5 波一隻，等級遞增。
- **特殊波次**：第 3 波小行星帶（擊碎會分裂）、第 4 波彈幕求生（只需閃避 20 秒）、第 6 波懸賞獵殺（25 秒內擊殺會逃跑、閃現、還擊的懸賞目標，+300 分與獎勵）、第 8 波護送運輸艦（運輸艦從左到右穿越戰區約 36 秒，敵人與子彈都會打它）、第 9 波防衛信標（守住中央信標 30 秒）、第 12 波小行星帶；第 10 波後有 40% 機率隨機出現。成功有分數加成與保證道具。
- **Boss 挑戰**：每一波都只出 Boss（隨機 1–6 隻），連續 8 波通關，分數與星塵 ×1.5；多人房間房主可勾選。
- **選單**：首頁依螢幕大小自動縮放，不出現捲軸；按下出擊即進全螢幕（手機並鎖橫向），右上 ⛶ 可切換。Boss 挑戰與單人出擊等寬等高；「遊玩說明」與「隱私說明」為彈出頁（右上 ✕ 關閉、Esc 也可）。
- **Esc 選單**：單人會暫停；多人不暫停。面板上有全螢幕鈕，按「繼續」會回到暫停前的全螢幕。按「離開」會**立即結束這局並結算**：單人上傳成績並顯示全球名次（畫面標題「撤退」），多人則離開隊伍、擊殺數仍計入隊伍的合作成績（隊伍全滅時結算）。結算畫面按 L 直接開排行榜。
- **打擊感**：吃到紅色炸彈的震動與慢動作以真實時間計，約 0.6 秒收掉，不再拖長。

所有數值集中在 `shared/constants.js` 的 `PLAYER_BASE`、`DIFFICULTY`、`AI`、`UPGRADE_EVERY_WAVES`、`WAVE_MODES`、`MODE_SCHEDULE`。

## 手機觸控

用手機瀏覽器開同一個網址即可，不用安裝。直向會提示轉橫向；按下出擊時自動進全螢幕。

- **左半螢幕**任一處按住拖曳 = 移動搖桿。
- **右半螢幕**按住拖曳 = 指定瞄準方向並開火；沒按時**自動瞄準最近的敵人並自動開火**（畫面上有黃色虛線提示）。
- **右下圓鈕** = 衝刺（圓弧顯示冷卻）。**右上 ☰** = 選單。
- 升級卡與結算畫面直接點擊。

觸控與鍵盤滑鼠可混用，偵測到第一次觸控就切換成觸控模式。

## 局外成長：星塵、機庫、每日挑戰

- **星塵**：每局結束依「分數 ÷ 25 + 每波 5」發放（上限 2000，任何分數都有），單人 / 每日由客戶端上傳時發、合作由伺服器結算時發給有帳號的隊員。結算畫面與選單都會顯示。
- **機庫**（選單「🔧 機庫」）：用星塵購買 7 種永久強化（裝甲塗層、起始護盾、牽引器、推進冷卻、幸運星、預備彈頭、星塵收集），每一局開局自動套用，多人房間也會套用。定義在 `shared/constants.js` 的 `PERKS`，價格與等級上限都在那裡改。
- **機體**（機庫上方）：4 種起始機，點選即出擊用；獵鷹免費，其餘用星塵解鎖。黃蜂（速度、射速 +25%，生命 70，衝刺冷卻 0.8 秒）、堡壘（生命 160、傷害 +30%、巨型彈體，速度 -20%、射速 -25%）、母艦（開局 2 台僚機、生命 110）。多人房間會驗證是否已解鎖，未解鎖一律退回獵鷹；大廳名單與戰場船身都會顯示機體。定義在 `shared/constants.js` 的 `SHIPS`。
- **每日挑戰**（選單「📅 每日挑戰」）：以台灣時間日期為種子，每天固定兩個規則（極速敵群、精英出沒、物資匱乏、玻璃大砲、雷射封鎖、蟲潮、深空突入、雷區）與固定的敵人組合；一個帳號一天一次（按下出擊就算用掉，重新整理也不能重來），獨立的今日榜。規則定義在 `shared/daily.js`。

## 帳號與全球排行榜

- **匿名帳號**：首次進站自動向伺服器註冊一組 id + secret，存在瀏覽器 localStorage，不需要密碼或信箱。改名字會同步。換瀏覽器或清除資料就是新帳號（抒壓小遊戲的定位，刻意不做登入）。
- **兩個榜**：單人（成績由瀏覽器回報）與合作（伺服器結算時自己記錄，無法竄改）；各有「全部」與「本週」。
- **結算畫面**顯示這局的全球名次；選單的「全球排行榜」可看前 20 名與自己的最佳成績、名次、局數。
- **API**：`POST /api/register`、`POST /api/rename`、`POST /api/runs`（單人 / 每日）、`GET /api/leaderboard?mode=solo|coop|daily&period=all|week`、`GET /api/me`（含星塵與永久強化）。

### 資料儲存

`server/db.js` 有兩個實作：
- 有 `DATABASE_URL` 環境變數 → **PostgreSQL**（自動建表）。
- 沒有 → **JSON 檔**（`data/store.json`，可用 `DATA_DIR` 改位置）。開發與測試用；在 Railway 上重新部署會清空。

Railway 會自動把 `DATABASE_URL` 注入到同專案的服務，重新部署後 `/health` 的 `db` 欄位會從 `file` 變成 `postgres`。

## 多人連線（最多 4 人）

1. 一位玩家輸入名字後按「建立房間」，取得 4 碼房號與邀請連結。
2. 其他玩家在選單輸入房號按「加入」，或直接開邀請連結（`?room=房號`）自動加入。
3. 大廳顯示所有人的名字，房主按「全員出擊」開始；遊戲中每個人頭上都有名牌與小血條。
4. **中途加入**：遊戲進行中用房號或邀請連結進來，會直接出現在戰場中央（3 秒無敵）。
5. **倒地救援**：血量歸零時倒地 30 秒，隊友靠近 3 秒即可救起（回復 50% 生命）；全員倒地才結束。單人模式沒有隊友，直接陣亡。
6. **斷線重連**：網路中斷後 15 秒內自動重連，接回原本的角色與升級。
7. 全員陣亡後房主按 Enter 或點擊可再來一局，Esc 回到大廳或首頁。

同一台電腦開兩個分頁就能測試。要和其他電腦連線，請把伺服器部署到網路上（見下方「下一步」），或在同一區網內用你的內網 IP（例如 `http://192.168.1.10:8765`）。

## 架構原則

- **固定世界尺寸 1600×900**：所有玩家看到同一個世界，畫面等比縮放加黑邊，不同螢幕比例下公平。
- **邏輯與呈現分離**：`game.js` 是唯一的權威模擬，可在 Node 執行；渲染、音效、特效只消費它的狀態與 `fx` 事件。
- **玩家是陣列**：敵人追最近的玩家、Boss 鎖定最近的玩家、升級每人各選、擊殺數個別記錄，全員陣亡才結束。
- **沒有 setTimeout**：所有延遲用世界時間排程（`world.timers`），確定性且可在伺服器重播。
- **只對本機的效果**：定格、色差、準星動畫透過 `fx.local(player)` 只對本機玩家觸發，隊友擊殺不會震你的畫面。

## 伺服器防護

- 壞的 URI（`/%`）回 400 而不是讓程序崩潰；每個房間的 tick 有 try/catch（出錯只銷毀那間房）；`process.on('uncaughtException' / 'unhandledRejection')` 只記錄。
- 每個 IP 的 POST 速率限制（每 10 秒 `RATE_LIMIT`，預設 40）；快速配對會重用空的公開房，不會被灌出無限房間。
- `/api/runs` 有分數合理性上限（`600 × (wave+2)²`），星塵碎片 `dustBonus` 上限 150；`/api/meta/run` 只收單人 / 每日（合作局的成就 / 任務由伺服器用自己的 `world.stats` 算，隨 `result` 廣播 `metaBy`），同帳號排隊、每 `META_MIN_GAP_MS`（預設 8 秒）一次。
- `/api/me`、`/api/meta`、`/api/daily` 憑證走 POST body（GET query 仍相容舊客戶端）；`/api/stats` 沒設 `ADMIN_KEY` 時只認 socket 來源是本機，有設則常數時間比對。
- 回應帶 `X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`；JSON 檔存檔先寫 .tmp 再改名，壞檔會拒絕啟動（不會默默清空）；Postgres 事件表保留 90 天。

## 網路架構

- **伺服器權威**：每個房間持有一個 `world`，伺服器以 30 tick 跑 `game.js` 的 `update()`。客戶端只送 `{ix, iy, angle, fire, dash}`，不送任何結果，無法作弊。
- **快照 + 插值**：每 tick 廣播 `snapshot.js` 產生的世界快照；客戶端保留前後兩份快照，落後兩個 tick（約 66 毫秒）做線性插值，畫面平滑。
- **fx 事件**：伺服器端的 `fx` 把每次呼叫記成 `[名稱, 玩家id 或 null, 參數]` 隨快照送出；客戶端只播放全域事件與自己的事件（別人的擊殺不會震你的畫面）。
- **客戶端預測**：自己的機體不等伺服器，本機用同一個 `stepPlayer()` 以固定 tick 先算；每筆輸入帶序號，伺服器依序處理並在快照回報已處理到哪一號；客戶端以權威狀態為起點重播未確認的輸入，差異用約 0.1 秒的平滑偏移吸收。其他玩家與敵人仍用插值。
- **協定**：JSON。客戶端 → `join / input(seq) / start / upgrade / leave`；伺服器 → `welcome / lobby / started / snap / error`。
